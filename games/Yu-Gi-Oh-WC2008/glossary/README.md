# Thuật ngữ Yu-Gi-Oh! WC2008

- Normal Summon = Triệu hồi Thường; Special Summon = Triệu hồi Đặc biệt; Tribute = Hiến tế.
- Graveyard = Mộ; banish/remove from play = Loại khỏi cuộc chơi.
- Remove a Counter = **gỡ Bộ đếm**, KHÔNG dịch thành loại khỏi cuộc chơi.
- Type = Tộc; Attribute = Thuộc tính. Không dùng từ "hệ" cho tộc.
- Spell/Trap = Phép/Bẫy; Set = Đặt úp; face-up/down = ngửa/úp.
- ATK, DEF, LP, Level và tên lá bài được trích dẫn phải giữ nguyên.
- Bảng thuật ngữ CSV đầy đủ vẫn đang lưu trong ZIP checkpoint A35; sẽ đồng bộ lên đây trong đợt cập nhật dữ liệu nền tiếp theo.
